# CHS 2024/2018 対応ワークシート

2024 年版 CHS コミットメントと 2018 年版コンテンツの対応関係を扱いやすく整理したワークシートです。  
コミットメントごとに要件と 2018 年版の関連セクション（パフォーマンス指標、基本行動、組織の責任、ガイダンスノート）をまとめて閲覧できます。

## 使い方

ブラウザから以下にアクセスしてください。

➡️ https://shoei05.github.io/chs/

主な機能:

- サイドバーからコミットメント（1〜9）を選択し、2024 年の要件と 2018 年版との対応内容を閲覧
- ヘッダーに 1〜9 のコミットメントアイコンを表示
- 各コミットメントの詳細ページには該当アイコンを表示
- 「PDFをダウンロード」ボタンから、選択中のコミットメントに関する 2024/2018 の対応内容を PDF で保存可能
- 参考リンクは新しいタブで開きます

## データについて

`scripts/generate_commitments.py` を実行すると、PDF や Markdown から抽出したデータを `public/data/commitments.json` に再生成します。  
ローカルでの再生成時は仮想環境に `markdown` パッケージをインストールし、以下を実行してください。

```bash
.venv/bin/python scripts/generate_commitments.py
```
